Hi! I'm **Joram Kate Leonardo**, a **Full Stack Web Developer** with **6+ years of experience** engineering, deploying, and maintaining mission-critical, database-driven information systems and enterprise web applications.

- 🌐 **Portfolio**: [jkleonardo.tech](https://jkleonardo.tech/)
